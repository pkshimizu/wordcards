# プルリクルール

- タイトルは Conventional Commits の形式にする（例: `feat: カードモードを追加する`）。squash でマージするので、タイトルがそのまま main のコミットになる。
- 本文は `.github/pull_request_template.md` の形に沿って書く。
  - 対応する Issue があれば `Closes #<番号>` を書く。
  - 「内容」に変更点を、「確認」に手元で実行して通したものを、「補足」に自分で決めたこと・残っている作業を書く。
- 1 つの PR は、1 つの Issue（仕様の PR なら 1 つの要件）に対応させる。
