# レビューの進め方

- 作業フォルダには依存パッケージが入っています（Tasuki が `npm ci` を実行済み）。必要なら `npm test`・`npm run lint`・`npm run typecheck` を手元で流して確かめます。
- 受け入れテスト（`npm run test:e2e`）と `npm run db:reset` は実行しません。実装の作業とローカルの DB を取り合うためです。CI の `e2e` の結果で確かめます。
- 細かい好みの違いは指摘しません。動作・保守に影響するものだけを指摘します。
- 仕様の PR のときは、要件を満たしているか、AC と文言が具体的か、AC が受け入れテストでそのまま確かめられるか、既存の画面と矛盾しないかを見ます。
