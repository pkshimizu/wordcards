# コンテキスト

## プロダクト

wordcards は、単語と意味をカードにして覚える小さな Web アプリです。カードの追加・編集・削除、一覧と検索、出題と採点、間違えたカードの復習、カードモード（1 枚ずつめくる）があります。

- 利用者は 1 人で、ログインはありません。
- 自律開発エージェントの練習用リポジトリです。機能はエージェントが仕様から作ります。壊れても困りませんが、実際のプロダクトと同じ手順（仕様 → Issue → 実装 → レビュー → CI → マージ）で進めます。

## 開発の進め方

- 仕様は `docs/specs/` に機能ごとに置きます。
- デザインシステムはまだありません。UI は既存の画面の見た目と書き方に合わせて作ります。UI のデザイン（モック）は、人が求めたときだけ作ります。
- main には直接 push しません。PR を作り、CI が通ってから squash でマージします。
- CI は `check`（lint・整形・型・単体テスト・ビルド）と `e2e`（受け入れテスト）の 2 つで、どちらも合格が必要です。

## この PC での注意

- 実装（プログラマー）は同時に 1 つだけ動かします。受け入れテストが、この PC のローカルの Supabase（DB の初期化を伴う）と開発サーバーのポートを使うので、2 つ同時に動かすと互いに壊します。仕様の作成・Issue の作成・レビューは、実装と同時に動かしてかまいません。
- `.conductor/` は以前使っていた別のツールの設定です。従いません。
